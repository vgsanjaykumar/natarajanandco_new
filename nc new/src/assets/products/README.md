# Product images

Drop official product photos here, named after the product slug:

    birla-opus-one-pure-elegance.webp
    birla-opus-alldry-wall-n-roof-12.webp
    ultratech-cement.webp

Any product with a matching file automatically shows it instead of the built-in
illustration (product cards, product page, related products, search).
Use square or 4:3 images (min 800 px wide), WebP or PNG, and only images you have
permission to use (brand/dealer portal assets or your own photos).
The full list of slugs is in `src/data/products.js`.
